# H3 iterative-Q 验证实验结论

本实验严格限定为 validation-only。控制器验证 seeds 为
`8100001–8100020`，model seeds 为 `0/1/2`；未访问正式 test seeds。

## 设置

- 数据采集 gate：required heads `3/5`，margin `0.4`，window/chunk
  `12/12`。
- 主评估 gate：required heads `4/5`，margin `0.4`，window/chunk
  `12/12`；`3/5` 作为次级评估。
- B：自然阶段比例，不做近重复降权。
- C：阶段采样温度 `0.5`，按 state + future-summary 的跨阶段近重复簇
  进行 inverse-cluster weighting。
- D：在 C 基础上增加优势分层权重；P2 预注册筛选后未进入递归阶段。

## 配对比较

- B-P4 相对 B-P2：`-0.3 kEUR/episode`，95% 分层 bootstrap CI
  `[-54.4, +64.2]`。自然混合的递归训练没有累计平均收益，且 p90
  从 `+46.0` 恶化到 `+85.3 kEUR`。
- C-P4 相对 C-P2：`-31.4 kEUR/episode`，95% CI
  `[-129.5, +75.9]`。点估计改善，同时 p90、venting 和 override
  均向好，但区间跨 0。
- C-P4 相对 B-P4：`-6.7 kEUR/episode`，95% CI
  `[-80.2, +57.2]`。C 的点估计最好，但尚不能证明稳定优于 B。
- C-P4 相对既有 one-shot matched：`-44.2 kEUR/episode`，95% CI
  `[-112.0, +21.4]`。点估计、p90、venting 和 override 均更好，
  但平均成本差仍未达到统计确定性。
- C-P4 相对既有 iterative G60-P4：`-16.1 kEUR/episode`，95% CI
  `[-92.5, +49.7]`。

## 数据诊断

- 每条 P4 分支约有 `3597–3599` 个 roots；跨 G0–G3 只有 5 个
  近重复簇、10 个 roots，effective-unique fraction 约 `99.86%`。
  因此，数据重复不是当前迭代收益不足的主要瓶颈。
- C-P4 将 G0/G1/G2/G3 的采样概率从自然比例约
  `60.0%/8.0%/12.0%/20.0%` 调整为
  `41.9%/15.2%/18.7%/24.2%`。相较于近重复降权，这种阶段 batch
  mass 重分配更可能解释 C 的方向性改善。
- G1 的强优势 roots 仅 `22.9%`，之后 G2/G3 约为
  `25–37%`；迭代数据的主要问题更像是弱优势和阶段分布，而不是
  大量复制。
- D 的优势分层在 P2 主评估中最差，因此当前的
  `0.5/1/2` 权重不应继续递归；它可能过度强调少量高优势 roots，
  降低状态覆盖和模型稳定性。

## 当前结论

本次结果不支持“只放宽采集 gate 就能稳定产生迭代收益”。自然迭代
B 到 P4 基本回到 P2 水平；C 表明阶段重平衡可能让递归数据变得更有用，
但 3 个 model seeds 下证据仍不足以宣称优于 one-shot 或 B。

因此，论文中现阶段可以支持的表述是：递归策略数据并非天然有效，其收益
依赖阶段分布控制；温和的 stage balancing 给出一致方向的改善信号，但仍需
独立验证或更多 model seeds 确认。正式 test seeds 应继续保持封存，直到
validation-only 方案和成功判据预先锁定。
