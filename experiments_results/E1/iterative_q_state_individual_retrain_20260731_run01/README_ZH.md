# Iterative Q 状态特征训练消融

## 结论

在当前 G60-P4 固定数据根、`unified_window_v1`、720 h 评估协议下，没有证据表明 `in_transit_fill` 或 `episode_progress` 是 iterative Q 训练所必需的。两者同时移除后，90 个“模型种子 × 场景”配对样本的平均总成本只增加 €2,655（+0.14%），跨模型种子与场景的 95% bootstrap 区间为 [−€66,011, +€76,992]，覆盖 0。

- 只移除 `in_transit_fill`：平均变化 −€20,348（−1.08%），95% CI [−€102,584, +€68,455]。
- 只移除 `episode_progress`：平均变化 −€97（−0.005%），95% CI [−€69,258, +€64,588]。
- 两者都移除：平均变化 +€2,655（+0.14%），95% CI [−€66,011, +€76,992]。

所有区间均覆盖 0；模型种子间波动明显，因此不能声称移除特征会提升性能，但可以判断当前协议不依赖这两个输入。若目标是简化观察空间，建议同时移除。

## 设计

- 始终移除已判定不应使用的 `hour_of_week`。
- 2×2 条件：保留两个目标特征、只删 `in_transit_fill`、只删 `episode_progress`、两个都删。
- 每个条件使用模型种子 0、1、2；训练数据根与迭代阶段完全相同。
- 每个模型在场景种子 9000031–9000060 上配对评估，共 90 个配对单元。
- 置信区间采用 30,000 次 crossed bootstrap，同时重采样模型种子和场景，随机种子为 20260731。

## 完整性检查

- 环境检查：SLURM 35843。
- 训练：35844、35846、35848；评估：35845、35847、35849。
- 所有 13 个 SLURM 单元均为 `COMPLETED`、退出码 `0:0`。
- 12 个训练/评估 `.err` 文件均为 0 字节，未检出 traceback、OOM 或 NaN/Inf。
- 相关本地单元测试：29 passed。

## 适用边界

此前自洽递归数据根的“两个都删”联合消融呈现 +2.61% 的方向性成本上升，但 95% CI 仍覆盖 0。该结果提示策略诱导的数据分布变化可能放大特征作用；本实验能严格回答固定数据根下的表示需求，不能证明所有递归训练分布下都完全等价。
